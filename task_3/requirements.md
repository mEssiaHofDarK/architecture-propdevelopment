# Список требований

## Требования к безопасности

| Категория                | Требование                                                                                                              |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **Классификация данных** | Биометрические шаблоны и автомобильные номера — **строго конфиденциальные данные**.                                     |
| **Хранение данных**      | Персональные и биометрические данные должны храниться **на территории РФ**, в соответствии с 152-ФЗ.                    |
| **Шифрование**           | Все передаваемые данные (включая видео, биометрию, номера авто) — только по **HTTPS/TLS 1.2+**.                         |
| **Минимизация данных**   | Партнёр не должен получать полные профили жильцов — только ID/токен доступа и разрешённый статус.                       |
| **Логирование и аудит**  | Все действия партнёрской системы (распознавание, открытие доступа) должны логироваться и быть доступны PropDevelopment. |
| **Разделение доступа**   | Партнёр не должен иметь возможность управлять или просматривать данные жильцов других жилых комплексов.                 |
| **Безопасность API**     | Все вызовы должны проходить через API Gateway PropDevelopment с проверкой токенов и ограничением IP.                    |
| **DDoS / Rate-limiting** | Ограничение частоты запросов и защита от массовых обращений к API (например, flood-атаки на распознавание).             |

## Протоколы аутентификации и авторизации

OAuth2

## Описание взаимодействия
### Интеллектуальный домофон
1. Организован видеопоток с распознаванием человека
2. Снятие биометрии с человека
3. Отправка запроса в tenant-core-app 
4. Ответ от tenant-core-app проживает ли данный человек в этом доме
5. Открытие двери

Дополнительно: поддержа функциональности стандартного домофана
### Интеллектуальный шлагбаум
1. Организован видеопоток с распознаванием подъехавшего авто
2. Определение номера авто
3. Отправка запроса в tenant-core-app 
4. Ответ от tenant-core-app принадлежит ли данный авто какому либо собственнику из этого дама/парковки
5. Открытие шлагбаума
